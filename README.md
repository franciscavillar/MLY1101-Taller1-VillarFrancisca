# MLY1101 - Taller 1

Taller de la asignatura **Machine Learning** enfocado en el consumo automatizado de APIs públicas.

## Objetivo

Recopilar información de personajes y criaturas de distintas franquicias de entretenimiento mediante tres APIs públicas.

## APIs utilizadas

* **PokéAPI** — 200 registros.
* **Digi-API** — 200 registros.
* **Rick and Morty API** — 200 registros.

En la API de Rick and Morty se utilizó paginación para completar los 200 registros.

## Resultado

Se obtuvieron **600 registros en total**, manteniendo cada dataset de forma independiente.
